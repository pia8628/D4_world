# Diablo IV Birthday Adventure / 暗黑破壞神 IV 生日冒險

## English

This repository contains a small text-based adventure inspired by the world of *Diablo IV*. The game was created as a programming exercise and as a birthday surprise for a friend. You will guide a brave Nephalem leader through three story-driven episodes, make dialogue choices, collect class-specific weapons, and fight bosses such as Elias and Lilith.

### Features
- Five playable classes: Barbarian, Sorcerer, Rogue, Druid, and Necromancer.
- Narrative-driven chapters with branching dialogue choices and typing-effect narration.
- Turn-based battles with two major bosses and multiple combat outcomes.
- Replay loop that lets you experience different choices and endings.

### Requirements
- Python 3.8 or later (the script only relies on the standard library).

### How to Play
1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the game with:
   ```bash
   python D4_HappyBirthday
   ```
4. Follow the on-screen narration and prompts to enter your name, pick a class, and decide how the story unfolds.

### Notes
- The game text is primarily in Traditional Chinese.
- Combat requires manual input for each turn (attack or defend) and continues until either side is defeated.
- After the finale you can choose to replay and try alternate paths.

## 中文

這個專案是一款以《暗黑破壞神 IV》為靈感的小型文字冒險遊戲，原本是為朋友準備的生日驚喜，同時也作為程式練習。玩家將扮演涅法雷姆的領導者，經歷三個故事章節，在旅途中做出抉擇、獲得職業專屬武器，並挑戰伊萊亞斯與莉莉絲等魔王。

### 遊戲特色
- 五種可選職業：野蠻人、法師、遊俠、德魯伊、死靈法師。
- 故事導向的章節，搭配分支選項與打字機效果敘事。
- 回合制戰鬥，面對兩位主要頭目並可能有不同結局。
- 結尾可選擇重新遊玩，體驗不同的故事線。

### 執行需求
- Python 3.8 以上版本（程式僅使用標準函式庫）。

### 遊玩方式
1. 下載或 clone 此資料庫。
2. 在終端機切換到專案目錄。
3. 以以下指令啟動遊戲：
   ```bash
   python D4_HappyBirthday
   ```
4. 依照螢幕提示輸入名稱、選擇職業並做出各種決定，完成冒險。

### 提醒
- 遊戲文本主要為繁體中文。
- 戰鬥為回合制，每回合需輸入攻擊或防禦，直到一方落敗。
- 完成結局後可選擇再次遊玩，探索不同選項。

祝你玩得開心，也祝福壽星生日快樂！
